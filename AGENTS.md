# Core agent guide

`Core` is a compatibility/legacy library outside the active Delta dependency
chain. Do not migrate or rename it as collateral work.

Use [WORKFLOW.md](WORKFLOW.md) for the bounded build. Create a local TODO/IDEAS
file only when the user explicitly selects work in this repository. Skills are
task-dependent; use `static-analysis` for dependency review and
`abi-and-calling-conventions` for interop/layout changes.
